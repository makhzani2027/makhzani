# فحص برنامج الحاسوب (أوفلاين) — الخطة والسجل

الطريقة: **فحص ← تسجيل ← إصلاح ← إعادة فحص**، بنداً بنداً حتى يصبح كل شيء ✅.
كل مشكلة تُسجَّل هنا برقم، وتبقى مفتوحة حتى يثبت الفحص الثاني أنها أُصلحت.

## الأدوار
| الدور | ماذا يفعل |
|---|---|
| الفاحص (١) — الخادم والبرنامج | يراجع الخلفية (قاعدة البيانات، واجهة البيانات، الحسابات، النسخ الاحتياطي، التحديث التلقائي، ويندوز) ويسجّل كل خطأ أو خطر |
| الفاحص (٢) — الواجهة | يراجع لوحة التحكم في وضع الحاسوب (كل صفحة، الطباعة، الصور، الأزرار التي تحتاج إنترنت) ويسجّل |
| الفاحص (٣) — الجولة الآلية | اختبار يفتح **كل صفحة** في البرنامج على قاعدة بيانات حقيقية ويسجّل أي خطأ أو طلب فاشل (يعمل على GitHub Actions مع كل تعديل) |
| المُصلح | يصلح البنود المسجّلة واحداً واحداً |
| المُعيد | يعيد الفحص الآلي واختبار ويندوز بعد كل إصلاح، ويغلق البند فقط إن نجح |

## المراحل
1. **التشغيل**: التثبيت، أول تشغيل، اختيار المجلد، إنشاء حساب، فتح حساب، إغلاق البرنامج وإعادة فتحه، حسابان على نفس الحاسوب.
2. **قاعدة البيانات وواجهة البيانات**: التشغيل على ويندوز، المنافذ، بقايا تشغيل سابق، OneDrive، تحديث قاعدة الحساب عند تحديث البرنامج.
3. **كل صفحات اللوحة**: المنتجات، المخزون، نقطة البيع، الفواتير، عروض الأسعار، الزبائن، الديون، التقارير، الإعدادات، الموظفون… بلا أخطاء.
4. **البيانات**: الصور (رفع وعرض)، الطباعة (إيصال، A4، عرض سعر)، الباركود، النسخ الاحتياطي والاسترجاع، ملف بيانات المتجر.
5. **بلا إنترنت**: لا شيء يحاول الاتصال بالإنترنت أو يتعطل بدونه، والصفحات التي تحتاج إنترنت مخفية.
6. **التحديث التلقائي**: الفحص، التنزيل، التثبيت عند الإغلاق، بقاء البيانات.
7. **الأمان**: عزل الحسابات، كلمات السر، الخادم المحلي لا يُفتح إلا على هذا الحاسوب.
