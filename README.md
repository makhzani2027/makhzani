# رَقيم — كلُّ قطعةٍ مرقومة.

نظام تجاري متكامل لمتجر ومخزن عراقي: **لوحة تحكم ومخزون** احترافية، **تطبيق متجر** على أندرويد، و**موقع تعريفي** — بقاعدة بيانات واحدة وهوية واحدة.

| | |
|---|---|
| 🖥️ `apps/admin` | لوحة التحكم والمخزون ونقطة البيع (React + Vite) ← `/dashboard/` |
| 📱 `apps/mobile` | تطبيق المتجر (Expo / React Native) |
| 🌐 `apps/site` | الموقع التعريفي (HTML/CSS/JS) |
| 🧩 `packages/shared` | الهوية، الأيقونات، عقد البيانات، التسعير، دورة الطلب — مع اختبارات |
| 🗄️ `supabase/` | قاعدة البيانات والصلاحيات والدوال |
| 🎨 `brand/` | الشعار والأيقونات |
| 🧭 `system/` | **التخطيط والقرارات والمهام والأسئلة — ابدأ من هنا** |
