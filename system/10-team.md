## القواعد
1. **لا تكتب خارج مجلداتك.** تحتاج تغييراً في `packages/shared` أو الهيكل المشترك؟ اكتبه في تقريرك النهائي تحت «طلبات للقائد» (الملف، التغيير، السبب) ولا تنفّذه.
   استثناء: إضافة اعتماديات في `package.json` لتطبيقك فقط.
2. **العقد مقدس**: أسماء الجداول والأعمدة والدوال من `packages/shared/src/types.ts` و`system/06-database.md` حرفياً.
   الواجهات تستدعي الدوال بالأسماء والمعاملات المذكورة هناك حتى قبل أن تكتمل قاعدة البيانات.
3. **الهوية**: الألوان والمقاسات من `theme.ts`، الأيقونات من `icons.ts`، الخط ثمانية، القواعد في `05-brand.md`. لا ألوان ثابتة، لا مكتبات أيقونات، لا إيموجي.
4. **اللغة**: كل نص في الواجهة عربي سليم بنبرة `05-brand.md`. الأرقام عبر `formatMoney/formatNumber/countOf`. الهواتف عبر `normalizeIraqiPhone`.
5. **وضع العرض**: كل شاشة تعمل ببيانات `@raqeem/shared/demo` عند غياب إعداد Supabase.
6. **لا تقل «يعمل» بلا تحقق.** قبل الإنهاء شغّل فحوص مجلدك (أدناه) وأصلح كل خطأ. ما لا يُختبر هنا (هاتف حقيقي، طابعة، بوابة دفع) اذكره صراحة.
7. **Git**: اعمل على فرعك في نسختك (worktree)، commits صغيرة واضحة بالإنكليزية، لا push (القائد يدمج). لا تعدّل `package-lock.json` يدوياً.
8. **الأسرار**: لا مفتاح سري في الكود. فقط متغيرات `EXPO_PUBLIC_*` و`VITE_*` العامة.
9. **الجودة**: TypeScript صارم بلا `any` إلا لسبب مكتوب. لا كود ميت، لا TODO بلا سبب. تعليقات قصيرة بالعربية تشرح «لماذا».

## فحوص كل مجلد
```bash
npm test                                         # shared (القائد)
npm run typecheck -w @raqeem/admin && npm run build -w @raqeem/admin
npm run typecheck -w @raqeem/mobile && (cd apps/mobile && npx expo export -p web --output-dir /tmp/web-export)
bash supabase/tests/run.sh                       # Postgres محلي: migrations مرتين + RLS + المنطق
# لقطات شاشة للتحقق البصري (Playwright + Chromium موجودان): انظر scripts/ في كل تطبيق
```

## التقرير النهائي لكل وكيل (بهذا الشكل)
1. **ما أُنجز** — قائمة بالملفات والميزات.
2. **التحقق** — الأوامر التي شُغّلت ونتيجتها الفعلية.
3. **ما لم يُنجز أو لم يُختبر** — بصراحة ولماذا.
4. **طلبات للقائد** — تغييرات مطلوبة في الملفات المشتركة.
5. **ملاحظات للوكلاء الآخرين** — أي افتراض يمسّهم.
