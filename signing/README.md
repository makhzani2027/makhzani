# signing/

مفتاح توقيع تطبيق رقيم لأندرويد، **مشفّراً** بـ AES-256 (openssl، pbkdf2، ٢٠٠٬٠٠٠ تكرار) بالجملة السرية `SIGNING_PASSPHRASE`.

- يُنشأ مرة واحدة من **Actions ← Create Signing Key** فيُضاف هنا الملف `raqeem-release.keystore.enc`.
- **Build Android** يفكّه وقت البناء فقط (لا يُحفظ مفكوكاً في أي مكان)، ويوقّع APK و AAB به عبر `scripts/apply-signing.js`.
- لا تحذف الملف ولا تغيّر الجملة السرية: ضياع أحدهما يعني أن التحديثات لن تُثبَّت فوق النسخ الحالية ولا تُقبل في Google Play.
  احفظ نسخة من الملف ومن الجملة السرية خارج GitHub.
- لا تضع هنا أبداً مفتاحاً غير مشفّر أو كلمة سر.
